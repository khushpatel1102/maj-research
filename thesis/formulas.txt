FORMULAS TO ADD TO THE THESIS — Chapter 3 (Methodology)
========================================================

For each: WHERE it goes, the SENTENCE before the equation, the EQUATION
(written in plain form), and how to type it in Word's equation editor
(Insert > Equation, then type — Word auto-formats most of this).

Number the equations (3.1), (3.2), ... at the right margin, as the DOE
template expects. In Word: after the equation, press Tab and type the
number, or use a right-aligned tab.


--------------------------------------------------------------------
FORMULA 1 — Cosine similarity
SECTION: 3.2.2 (The Memory-Assisted Judge), where retrieval is described.
--------------------------------------------------------------------

SENTENCE BEFORE:
"Similarity between the embedding of the response under evaluation and
the embedding of a stored node is measured by cosine similarity:"

EQUATION (3.1):
        sim(a, b) = (a · b) / (||a||  ||b||)

WORD EQUATION EDITOR — type:
   sim(a,b) = (a \cdot b)/(\|a\| \|b\|)
   (in Word: "a\cdot b" gives a·b ; "\|" gives the norm bars ;
    use the fraction template for the division)

SENTENCE AFTER:
"where a and b are the 1536-dimensional embedding vectors. A stored node
is retrieved only if its similarity exceeds the threshold for its type."


--------------------------------------------------------------------
FORMULA 2 — UCT selection rule (MCTS)
SECTION: 3.2.3 (Exploratory MCTS Components), where MCTS-Judge selection
is described.
--------------------------------------------------------------------

SENTENCE BEFORE:
"At each step of the tree search, the child node maximising the Upper
Confidence Bound for Trees (UCT) score is selected:"

EQUATION (3.2):
        UCT(s) = Q(s) + c * sqrt( ln(N(parent)) / N(s) )

WORD EQUATION EDITOR — type:
   UCT(s) = Q(s) + c \sqrt(ln N_p / N(s))
   (use the \sqrt template ; "N_p" gives N with subscript p)

SENTENCE AFTER:
"where Q(s) is the mean reward of node s, N(s) is its visit count,
N(parent) is the parent's visit count, and c controls the balance
between exploiting high-reward branches and exploring less-visited ones."


--------------------------------------------------------------------
FORMULA 3 — Accuracy
SECTION: 3.6 (Statistical Methodology), as the primary metric.
--------------------------------------------------------------------

SENTENCE BEFORE:
"The primary metric is accuracy, the proportion of test samples on which
the judge's verdict matches the ground-truth label:"

EQUATION (3.3):
        Accuracy = (number of correct verdicts) / (number of completed samples)

WORD EQUATION EDITOR — type:
   Accuracy = (\sum from i=1 to n  1[y_i = y ̂_i]) / n
   (simplest acceptable form: just write it as the fraction above ;
    if you want the indicator-sum form, use the summation template)

SENTENCE AFTER:
"Samples that errored after retries are excluded from n, as described in
Chapter 4."


--------------------------------------------------------------------
FORMULA 4 — Wilson score confidence interval
SECTION: 3.6 (Statistical Methodology), where Wilson CIs are introduced.
--------------------------------------------------------------------

SENTENCE BEFORE:
"Every accuracy is reported with a two-sided Wilson score confidence
interval. For an observed proportion p over n samples, with z the
standard-normal quantile for the chosen confidence level, the interval
is:"

EQUATION (3.4):
   ( p + z²/2n  ±  z * sqrt( p(1-p)/n + z²/4n² ) ) / ( 1 + z²/n )

WORD EQUATION EDITOR — type as one large fraction:
   numerator:   p + z^2/2n \pm z \sqrt(  (p(1-p))/n + z^2/(4n^2)  )
   denominator: 1 + z^2/n
   (use the fraction template for the whole thing, and \pm for ±,
    \sqrt for the square root, ^2 for the squares)

SENTENCE AFTER:
"The Wilson interval is preferred over the normal-approximation interval
because it remains well behaved at the moderate sample sizes used here
and never extends below zero or above one."


--------------------------------------------------------------------
FORMULA 5 — McNemar exact test statistic
SECTION: 3.6 (Statistical Methodology), where paired comparison is
described.
--------------------------------------------------------------------

SENTENCE BEFORE:
"Two modes are compared on the identical test items. Let b be the number
of items the first mode gets right and the second wrong, and c the
number it gets wrong and the second right. Under the null hypothesis of
no difference, the two-sided exact McNemar p-value is computed from the
binomial distribution:"

EQUATION (3.5):
   p = 2 * sum_{k=0}^{min(b,c)}  C(b+c, k) * (1/2)^(b+c)

WORD EQUATION EDITOR — type:
   p = 2 \sum from k=0 to min(b,c)  (\binom(b+c)(k)) (1/2)^(b+c)
   (use the summation template ; \binom gives the C(n,k) bracket form)

SENTENCE AFTER:
"A difference is declared statistically significant only when this
p-value is below 0.05 and the paired bootstrap confidence interval on
the accuracy difference excludes zero."
